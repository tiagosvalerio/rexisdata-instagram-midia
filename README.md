# RexisData · mídia do Instagram

Imagens públicas dos carrosséis publicados no Instagram [@rexisdata_oficial](https://www.instagram.com/rexisdata_oficial/).
A API do Instagram só publica imagens a partir de um link público, e este repositório serve esses arquivos.

Cada carrossel fica em `carrosseis/<data>-<assunto>/`, com os slides numerados (`01.jpg`, `02.jpg`, …).
Só entra aqui o que foi aprovado para publicação.
